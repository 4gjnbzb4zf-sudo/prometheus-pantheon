# Prometheus — social media kit

All assets are generated from `source/prometheus-pantheon-original.jpg` by `build.py`
(`python3 media/build.py`; needs Pillow). Change sizes/positions there and re-run.

| File | Use |
|---|---|
| `avatar/avatar-monogram-640.png` | **Telegram channel/group photo**, X / Discord avatar (round-safe "P") |
| `avatar/avatar-monogram-512.png` | Same, smaller |
| `avatar/avatar-wordmark-640.png` | Alternative avatar with the full wordmark (hard to read at small sizes) |
| `avatar/preview-round-*.png` | Previews of how the avatars look once cropped to a circle |
| `banners/x-header-1500x500.jpg` | X / Twitter header (kept clear of the profile picture area) |
| `banners/og-link-preview-1200x630.jpg` | Website link preview (og:image), Telegram/X link cards |
| `banners/discord-banner-960x540.jpg` | Discord server banner / invite splash |
| `banners/linkedin-cover-1584x396.jpg` | LinkedIn page cover |
| `banners/youtube-2560x1440.jpg` | YouTube channel art (logo inside the safe zone) |
| `posts/square-post-1080.jpg` | Announcement / pinned post image |
| `posts/story-1080x1920.jpg` | Stories (Telegram / Instagram) |
